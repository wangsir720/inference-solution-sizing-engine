## 可信等级

| 等级 | 含义 | 在测算中的作用 |

| `official` | 厂商官方文档 / 官方仓库 | 可直接作为依据 |

## 关键说明：哪些数据不可信，为什么

1. **S3 与 REX-S 的详细规格标 `unverified`** —— 公开报道给出了「推理性能提升 3 倍、
   成本降 90%、支持 FP4/FP8、超大显存」等结论性表述，但**未给出可回溯的完整参数表**。
   本项目因此只采用显存容量与 TDP 两个可引用字段，其余标「未查到」。

2. **加速卡单价未公开** —— 厂商未公开统一售价，属商业信息。
   TCO 中该项列为「未查到」并从总额剔除，**不用估算值填充**。

3. **竞品数据用 official 级** —— A100/L40S/MI300X 的规格 NVIDIA/AMD 官网均可查，
   但本项目**只做规格并列，不做优劣评价**。

4. **本项目无任何 `official` 级的曦望数据** —— 官网以产品宣传与技术叙事为主，
   无参数表。这意味着所有涉及曦望的测算都是**基于公开报道的理论推算**，
   这一点在 README 与每份输出中显式声明。

## 与既有作品集的边界

本项目**不做硬件选型评分、不做多厂商打分发榜**。

已有的 `solution-sizing-engine`（行业解决方案测算引擎）做的是「算力配置 + 三年 TCO + 迁移路径」，
本项目在其上做**推理场景的深化**，新增三项它没有的：

1. **KV Cache 显式显存测算**（推理场景的瓶颈常在 KV cache 而非权重）
2. **张量并行 / 专家并行策略与通信代价**
3. **每瓦 Token 吞吐量**（推理专用指标）

已有的 `ai-compute-presales-workbench` 做的是通用算力选型，本项目**不重做通用选型**。
