# 客户理解成本清单

> 用途：售前沟通前自查。**客户问什么、我们怎么答、哪些说法会弄丢订单。**

| 客户会问 | 怎么答 | 哪些说法有风险 |
|---|---|---|
| 推理卡和训练卡到底差在哪？ | 训练卡优化的是大规模矩阵乘的峰值吞吐；推理卡优化的是访存效率与单位功耗吞吐。训练卡做推理时，大量算力在等显存搬运。 | 不要说「我们比 A100 快 X 倍」—— 那是训练口径的数字，推理场景客户会立刻质疑 |
| 每瓦 Token 吞吐和 TFLOPS 什么关系？ | TFLOPS 衡量算力峰值，Token/瓦衡量实际业务产出。推理场景客户的采购依据是后者：每 Token 电费直接决定运营成本。 | 不要用 TFLOPS 作为主指标，客户会认为你没理解推理的成本结构 |
| 为什么不用 HBM 而用 LPDDR？ | LPDDR 成本与容量优势明显，推理场景的访存模式对带宽要求低于训练。代价是带宽上限较低，需要靠架构与编译优化弥补。 | 必须主动说明带宽差距，否则客户会认为这是降级选择 |
| CUDA 兼容到什么程度？我的代码要改多少？ | 主流框架与算子已适配，迁移路径为「不改模型结构、替换算子库」。具体工作量需按客户实际模型评估。 | **不要承诺零成本迁移**—— 个别自定义算子确实需要改写，夸大会在 POC 阶段暴露 |
| 从卡到一体机多久能交付？ | 需按采购量与定制程度评估。标准形态交期短，深度定制需评审。 | 不要给具体天数承诺，除非已有供应链确认 |
| 总拥有成本和通用 GPU 方案比差多少？ | 推理场景的 TCO 由电费主导，因此关键指标是每 Token 电费。需要客户提供用电电价、运行小时数、利用率才能给出可比数字。 | **不要在不知道客户电价的情况下给 TCO 数字**—— 电价差 0.2 元就会让结论反转 |

**使用方式**：POC 前逐条过一遍，凡是无法给出可验证答案的条目，都应在会前补齐材料。
